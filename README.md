# 硬派番長ストリート

熱血硬派くにおくん風のベルトスクロール・アクションゲーム（1面のみ）。
`game/index.html` 1ファイルだけで動きます。スマホ（タッチ操作）優先。

## 遊び方
`game/index.html` をブラウザで開く（GitHub Pages などに置けばスマホからも遊べます）。

| 操作 | スマホ | キーボード |
|---|---|---|
| 移動 | 左側のスティック（どこを触っても出る） | 矢印 / WASD |
| パンチ | パンチ | Z / J |
| キック | キック | X / K |
| ジャンプ | ジャンプ | C / Space / L |
| ダッシュ | 左右に2回すばやく入力 | →→ / ←← |

- パンチ3連打で最後はアッパーでふっとばし
- ジャンプ中にパンチかキックでとびげり
- ダッシュ中の攻撃は強力なダッシュパンチ / キック
- ふっとばした敵は、ほかの敵をまきこむ
- 3波目のあとに出る肉まんで体力回復
- 最後は三号倉庫の番長リュウジとの対決
